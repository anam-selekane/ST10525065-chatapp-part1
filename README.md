## Description:
Chatapp ia a Java-Based application made to handle the users registration and login.
This project app focuses on ensuring that the user enters valid information under the setted conditions on the app.
The project is part1 for my Programming PoE.
---

## Features
* **Username Validation:** It ensure that the user has only inserted a username that contains only 5 characters length and it also comtains an underscore (_).
* **Password:** Validates that the user's password is atleast 8 characters long and that it contains a capital letter,a number,and also a special character.
* **Phone Number:** Confirms that the cellphone number contains the South African international code (+27) and after has 9 digits.
* **Automated Testing:**Use JUnit 5 to the validation logic to ensure that the methods work and that they can provide a valid response.
